# Sky Scan (Weather report app)

This is a very simple front-end weather app that shows **real-time weather** for a city using the **OpenWeatherMap** public API.  
It is written with **HTML, CSS, and plain JavaScript**.
## How to run

1. Download or clone this folder to your computer.
2. Open `index.html` in your browser (you can just double-click it).
3. Type a city name (for example: `London`) and click **Get Weather**.


## What this app shows

- City name and country
- Current temperature in °C
- Short description (like "clear sky", "light rain")
- Weather icon
- Humidity
- Wind speed

 Everything runs in the browser using a public, free API key from OpenWeatherMap.
